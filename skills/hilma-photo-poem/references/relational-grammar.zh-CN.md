# Hilma af Klint：关系语法而非图形套件

本参考用于生成抽象面板前的构图判断。它不是艺术史百科，也不授权复制任何作品；目标是避免把 af Klint 的语言简化成圆圈、花瓣和粉彩。

## 研究结论

- 《The Paintings for the Temple》的整体主题是由极性推动的人类与意识演化。重要的不是某个孤立符号，而是两个状态如何相遇、对抗、镜像、转化并趋向整体。
- “Dual”指互补原则与品质共同构成完整，不应被理解成寻找浪漫伴侣。生成时只借用“互补—转化—完整”的关系逻辑，不给照片中的人物、地点或事件附会性别或灵性含义。
- 《Evolution》通过男性/女性、光/暗、善/恶等极性的互动表达发展，并以水平和垂直镜像寻求平衡。因此直线、轴、分区、反射、方向和尺度转换与圆形同样关键。
- 《The Swan》在系列内部从具象的黑白对偶逐步走向分区、楔形、螺旋和纯几何，说明风格来自连续转化，而不是固定符号库存。
- 她把自然、科学和神秘视为理解生命结构的相通路径：植物形态可被抽象成生长轴、分枝和细胞变化；几何可以表现秩序、阶段、穿越和系统关系。
- 作品通常属于序列，前后图像互相发展。单张生成也应让元素呈现“从 A 到 B”的过程，而不是若干互不相关的漂亮图标。

## 理论优先级与创新边界

- 每次创作先选择一种理论操作：极性如何相遇、差异如何互换属性、一个状态如何演化为另一个状态、局部如何进入更大的整体。形式选择必须服务于这项操作。
- 创新发生在这套理论内部：为当前照片发明新的转化路径、过渡形、尺度阶段或几何—植物连续体，而不是借助随机怪异、表现主义爆发或无来源的神秘符号制造“新鲜感”。
- 图解秩序是骨架，生命形态是生长。两者缺一都会偏离：只有秩序会变成现代主义几何海报；只有生长会变成泛化的生物形态或超现实抽象。
- 平衡不等于机械对称。偏移、差异和未闭合可以存在，但应来自极性与演化过程，而不是作为每张画都必须添加的创意效果。
- 真实 af Klint 参考可帮助判断形式语法；过去生成的图片只能用于事后反思，绝不能作为下一张图的视觉输入。否则偶然特征会递归放大，逐渐替代艺术家的理论框架。

## 从照片选择关系语法

先写出照片中最强的三个关系，再选择一项主语法和至多两项辅助语法。下表是启发，不是照片到形状的强制映射：

| 照片事实 | 优先形式 | 不要默认 |
|---|---|---|
| 地平线、墙面、海岸、阴影边界 | 横带、切分、上下呼应、偏移镜像 | 一排圆 |
| 道路、洞口、树干、塔、人物站立 | 纵轴、门形、阶梯、收束或展开 | 中心曼陀罗 |
| 建筑立面、窗、重复柱列 | 网格、刻度、成组直线、缺口 | 细胞泡泡 |
| 枝叶、水流、云、路径 | 分枝、曲线束、方向场、汇流 | 装饰花瓣 |
| 包围、岛屿、容器、太阳、果实 | 环、椭圆、内外层、偏心圆 | 机械同心圆 |
| 两个明确主体或两个色域 | 相向/背离、镜像中的差异、交叠产生第三形 | 固定蓝黄双圆 |
| 远近、成长、时间或尺度变化 | 递进、阶梯、由密到疏、形态连续变换 | 无关联的小图标 |

## 形体自由与照片关联

- 不设置任何“直线至少多少”“圆最多多少”之类的形状配额。配额会把风格变成机械检查表。
- af Klint 对圆、椭圆、螺旋和卵形的使用可以很大胆。关键不是克制圆的数量，而是让圆承担孕育、包容、相遇、分裂、融合、周期或尺度变化，并与线、色带、植物曲线或其他圆发生因果关系。
- 照片结构若天然适合圆形，可保留其包围、中心或循环关系；若不适合，也可以舍弃形体一致性，用圆形重新组织照片中的色彩张力、明暗互补或情绪节奏。
- 不必保存完整空间结构。地平线、透视、物体位置和轮廓都可被删除、移位或重组，只保留最能支撑作品的少数关系。
- 即使空间结构被舍弃，作品仍必须与照片属于同一视觉世界。优先通过主色面积顺序、冷暖关系、最深与最亮色的角色、局部强调色、运动方向和密度变化建立这种亲缘性。
- “传神”优先于“形似”：画面应保留原图的开放/压迫、安静/躁动、靠近/远离、包围/穿越等感受，而不是把原图换成几何轮廓图。

## 构图检查

生成提示必须能回答：

1. 为什么这一张需要圆、直线、三角、网格或曲线？答案可以来自照片关系，也可以来自对照片色彩、情绪和生命节奏的传神转译，但不能只是“因为像 af Klint”。
2. 主元素如何影响其他元素：穿过、支撑、分割、包围、镜像、汇合，还是演化？
3. 是否出现了第三种状态，体现两个色域或方向相遇后的变化？
4. 删除任一主要元素后，关系是否会受损？若不会，它可能只是装饰。
5. 第一眼是否是一套完整结构，第二眼才通过色彩、气息或少数关系隐约对应照片？若直接看到树、楼、海或人，仍然太具象；若完全看不出属于同一视觉世界，则关联又太弱。
